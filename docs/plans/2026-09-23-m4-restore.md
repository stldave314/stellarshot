# M4: Restore, implementation plan

**Goal:** A complete restore inside the app:
- **Browse:** any snapshot as a file tree, with search, and every version of a file.
- **Deleted files:** files that are in backups but no longer on disk.
- **Compare:** any two snapshots.
- **Restore:** selected files and folders, to their original place or another folder. When a file already exists: overwrite, keep both or skip, with a dry-run summary before anything is written.

**Architecture:**
- **`engine::browse::Browser`** holds one opened, tree-indexed repository for the life of the restore page, so every listing, search, version lookup and comparison reuses the loaded index instead of re-reading it. It's `Send + Sync` (a `Mutex` inside) and is used from blocking tasks.
  - Comparison walks two trees side by side and skips any subtree whose tree ID is the same in both, so unchanged folders are never read.
- **`engine::restore`** gains selective restore:
  - A `RestoreRequest` has a snapshot, the paths, the target (original place or a folder) and a conflict policy.
  - The conflict policy is applied to the `(path, node)` stream rustic's `prepare_restore` consumes. **Skip** drops existing files, and **Keep both** renames them to `name (restored YYYY-MM-DD).ext`. **Overwrite** passes them through, and rustic itself leaves identical files alone.
  - `delete: true` is never used.
- **Restoring runs in the child process** (`--run restore`), with progress and Cancel. The dry-run preview runs in-process on a blocking thread.
- **UI:** `app/pages/restore.rs`, opened by **Restore…** on a profile page. It has three tabs, a selection, and a restore dialog with the dry-run summary.

**Spec:** §6.3

## Review focus

1. **Restoring to the original place over a file that changed since.** Keep both must not touch the existing file. Test: `keep_both_never_touches_the_existing_file`.
2. **Skip with a folder where some files exist and some don't.** The missing ones are restored and the existing ones left alone. Test: `skip_restores_only_what_is_missing`.
3. **The dry run and the real run disagree.** The preview's counts must match what the restore then does. Test: `preview_counts_match_the_restore`.
4. **A snapshot path that no longer exists in the live filesystem**, for example a deleted folder restored to its original place. Parents are created. Test: `restores_into_a_deleted_folder`.
5. **Comparing a snapshot with itself.** No differences, and no tree is read below the root. Test: `a_snapshot_compared_with_itself_has_no_changes`.

### Task 1: Browser (`src/engine/browse.rs`)
```rust
pub struct TreeEntry { pub name: String, pub path: PathBuf, pub kind: EntryKind, pub size: u64, pub modified: Option<i64> }
pub enum EntryKind { File, Directory, Symlink, Other }
pub struct FileVersion { pub snapshot: SnapshotSummary, pub size: u64, pub modified: Option<i64>, pub same_as_newer: bool }
pub enum Change { Added, Removed, Modified }
pub struct DiffEntry { pub path: PathBuf, pub change: Change, pub is_dir: bool, pub size: u64 }
pub struct MissingEntry { pub path: PathBuf, pub is_dir: bool, pub size: u64, pub last_seen: SnapshotSummary }
impl Repo { pub fn browse(self) -> Result<Browser, EngineError> }
impl Browser {
    pub fn snapshots(&self) -> &[SnapshotSummary];
    pub fn list(&self, snapshot: &str, dir: &Path) -> Result<Vec<TreeEntry>, EngineError>;
    pub fn search(&self, snapshot: &str, query: &str, limit: usize) -> Result<Vec<TreeEntry>, EngineError>;
    pub fn versions(&self, path: &Path) -> Result<Vec<FileVersion>, EngineError>;
    pub fn diff(&self, from: &str, to: &str) -> Result<Vec<DiffEntry>, EngineError>;
    pub fn missing(&self, scope: &Path, since: i64, limit: usize) -> Result<Vec<MissingEntry>, EngineError>;
}
```
**Tests:** `lists_a_folder_in_a_snapshot`, `search_finds_names_anywhere`, `versions_collapse_identical_content`, `diff_reports_added_removed_modified`, `a_snapshot_compared_with_itself_has_no_changes`, and `missing_finds_deleted_files_with_their_last_snapshot`.

### Task 2: Selective restore (`src/engine/restore.rs`)
```rust
pub enum Target { Original, Folder(PathBuf) }
pub enum ConflictPolicy { Overwrite, KeepBoth, Skip }
pub struct RestoreRequest { pub snapshot: String, pub paths: Vec<PathBuf>, pub target: Target, pub policy: ConflictPolicy }
pub struct RestorePreview { pub files: u64, pub bytes: u64, pub unchanged: u64, pub conflicts: u64 }
impl Repo {
    pub fn preview_restore(self, request: &RestoreRequest) -> Result<RestorePreview, EngineError>;
    pub fn restore(self, request: &RestoreRequest, progress: Arc<dyn ProgressSink>) -> Result<RestorePreview, EngineError>;
}
```
**Tests:** the review focus 1 to 4, plus `restore_to_a_folder_keeps_names`.

### Task 3: Runner
`Job.restore: Option<RestoreRequest>` and `--run restore`. The old whole-snapshot `restore_all` stays for the tests that use it.

### Task 4: Restore page (`src/app/pages/restore.rs`)
- **Tabs:** Browse (snapshots, then files with a breadcrumb and search, then versions), Deleted files (scope folder and window), Compare (two snapshot pickers).
- **Selection:** checkboxes, plus a bottom bar with the count and **Restore…**
- **Restore dialog:** target, policy, a dry-run summary, then **Restore**. Progress and Cancel appear on the page.
- **Open copy:** a single file, restored to a private temporary folder and opened read-only.
